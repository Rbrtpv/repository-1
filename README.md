# repository-1

A lightweight static task app built with HTML, CSS, and vanilla JavaScript.

## Features

- Add new tasks.
- Mark tasks as complete.
- Filter by all, active, or completed tasks.
- Clear all completed tasks.
- Persist tasks in browser local storage.

## Run locally

Open `index.html` directly in a browser, or serve the directory with a simple static server such as:

```bash
python3 -m http.server 8000
```
